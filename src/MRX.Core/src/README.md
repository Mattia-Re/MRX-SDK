# MRX.Core

Core ASP.NET Core building blocks for the MRX SDK: model binding configuration, `ProblemDetails`
extensions, and object model validation extensions. Requires the ASP.NET Core shared framework (server-side only —
see [MRX.Core.Common](https://github.com/Mattia-Re/MRX-SDK) for the
framework-agnostic types shared with client/Blazor WASM projects).

```
dotnet add package MRX.Core
```

Part of the [MRX SDK](https://github.com/Mattia-Re/MRX-SDK).
